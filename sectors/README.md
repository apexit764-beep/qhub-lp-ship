# رسمات بلاطات القطاعات

| الملف | البلاطة | النوع |
|---|---|---|
| `retail.png` | التجزئة والضيافة (عريضة) | **PNG مقصوص بخلفية شفافة** |

> بلاطتا **صنّاع المحتوى** و**التجميل والعناية** تستخدمان فيديو
> (`public/videos/`) — شوف الـREADME هناك.

## الفرق بين النوعين

- **cutout** (المستخدم هنا): PNG بخلفية شفافة يتوضّع في المساحة الفاضية
  جنب النص، وخلفية البلاطة المتدرّجة تبقى ظاهرة حواليه. هذا ستايل المرجع.
- **image / video**: تملأ البلاطة كاملة خلف حجاب غامق والنص فوقها.

`Sectors.tsx` سيرفر كومبوننت يتحقّق من وجود الملفات وقت البناء — حطّ الصورة
وأعد البناء وبتظهر، بدون تعديل كود. ولو مو موجودة تبقى البلاطة بتدرّجها
المصمّم وأيقونتها المكبّرة، وما فيه طلب 404.

## مواصفات الـPNG المقصوص

- **الخلفية:** شفافة إلزامياً — البلاطة زرقاء غامقة، وأي خلفية بيضاء بتبان
- **المقاس:** ‎900×700 تقريباً، والعنصر يملأ الإطار بهامش بسيط
- **الحجم:** أقل من 250 كيلو
- **المحتوى:** العنصر يجلس فوق خلفية غامقة — فالتفاصيل الغامقة جداً تضيع.
  الأفضل ألوان متوسطة إلى فاتحة، وحواف واضحة.
- **الموضع:** يتوضّع في الطرف الأيسر من البلاطة العريضة بعرض 38% تقريباً،
  و`object-contain` فالنسبة محفوظة وما ينقصّ.

## تحويل بلاطة أيقونة إلى بلاطة وسائط

في `SECTORS` داخل `Sectors.tsx`، بدّل البلاطة من:

```ts
kind: "icon", tint: "tint-2",
```

إلى واحد من هذول:

```ts
// PNG مقصوص جنب النص
kind: "media",
gradient: "linear-gradient(...)",
cutout: publicFile("sectors/اسم-الملف.png"),

// أو صورة تملأ البلاطة
kind: "media",
gradient: "linear-gradient(...)",
image: publicFile("sectors/اسم-الملف.jpg"),

// أو فيديو يملأ البلاطة
kind: "media",
gradient: "linear-gradient(...)",
video: publicFile("videos/اسم-الملف.mp4"),
poster: publicFile("videos/اسم-الملف-poster.jpg"),
```

الـ`gradient` يبقى في الحالات كلها — هو الخلفية تحت الـPNG المقصوص،
وهو البديل لو الملف مو موجود.
